## ⚡ Visão Geral

O **Career Command Center** é um portfólio moderno estilo cockpit/cyberpunk desenvolvido em React, TypeScript e Tailwind CSS. Reúne projetos interativos de simulação de redes, inteligência artificial, IoT e ferramentas de alta fidelidade.

### 🚀 Destaques:
- **CLI Terminal Integrado:** Terminal emulado navegável para interações rápidas (`projects`, `skills`, `contact`, `matrix`).
- **Bento Grid de Projetos:** Cards detalhados com badges de status em tempo real e links diretos para deploys e repositórios.
- **Matriz de Habilidades & Engenharia:** Radar técnico dividido entre Frontend, Backend/Sistemas e IA/Agentes Autônomos.

---

## 🛠️ Stack Tecnológica

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Build Tool:** Vite
- **Deploy:** Vercel
